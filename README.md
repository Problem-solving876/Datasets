This repository contains datasets prepared using different sliding window sizes for the analysis. Each dataset was generated by applying a specific sliding window to the original data.
The sliding window sizes are, 6-moves, 7-moves, 8-moves, 10-moves, 12-moves, 15-moves, 20-moves, 30-moves.

The filenames indicate the sliding window size used during dataset preparation. The number preceding rows represents the number of moves included in the sliding window. 
As an example, file name 6rows_solved_vs_unsolved indicates that the dataset was prepared using sliding window size 6.
